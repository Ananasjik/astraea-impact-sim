# План: Научная 3D-симуляция столкновения планет с процедурной биосферой

## Требования и принятые решения

### Требования (`R-n`)
- **R-1 (Организация воркспейса):** Сохранить прежний проект *Browser Factory Game* в `archive/factory-game/`, разместить новую симуляцию в корне `/home/slava/antigravity/Web game 1`, инициализировать Git и вести `.agents/MEMORY.md`.
- **R-2 (Физический 3D GPU-солвер):** Вычислительный движок на **C++20 + CUDA (`sm_89`)** для RTX 4050, поддерживающий **100 000+ частиц** в реальном времени: 3D SPH (ядро Wendland $C^2$, плотность с коррекцией на разрыв материалов, искусственная вязкость Монагана + ограничитель сдвига Бальзары), самогравитация **Barnes-Hut** на 3D-октодереве (Morton-сортировка через `CUB`), уравнения состояния **Tillotson EOS** (железо, силикат/гранит, вода/лёд) и политропного/идеального газа, упруго-пластическая прочность на сдвиг и модель хрупкого разрушения (damage $D \in [0, 1]$), радиационное охлаждение ($\sigma T^4$), адаптивный симплектический интегратор Leapfrog (Kick-Drift-Kick).
- **R-3 (Разнообразие типов планет и гидростатическое равновесие):** Генератор планет в честном **гидростатическом равновесии** (интегрирование 1D радиального профиля $\frac{dP}{dr} = -\frac{G M(r) \rho(r)}{r^2}$ + SPH-релаксация) для 5+ архетипов:
  1. **Живая биосферная планета (Терра / Экзо-Гея)** — железное ядро, силикатная мантия/кора, жидкая гидросфера (океаны), атмосфера, климатические пояса.
  2. **Железо-ядерная планета (тип Меркурия / хтоническое ядро)** — массивное ядро (~65–70% массы), тонкая хрупкая силикатная мантия.
  3. **Ледяной / Океанический мир** — каменное ядро, мантия из льда высокого давления / жидкого океана, ледяная кора.
  4. **Вулканический / Лавовый мир (Ио-подобный)** — частично расплавленная мантия с низкой сдвиговой прочностью, высокая начальная температура и светимость.
  5. **Газовый гигант / Суб-нептун** — тяжёлое каменно-ледяное ядро и глубокая сжимаемая оболочка $H_2/He$.
  6. **Рыхлый планетезималь / Протопланета (типа Тейи)** — пресеты гигантских импактов.
- **R-4 (Потоковый сервер и Headless-режим):** Однобинарный C++20-сервер (`sim_server`) со встроенным POSIX HTTP (раздача статики), RFC 6455 бинарным WebSocket-стримингом (упакованные кадры 16–20 байт/частица для 100k+ частиц без GC-пауз, команды управления в JSON) и `--headless`-режимом для детерминированных физических прогонов и тестов.
- **R-5 (Бесшовный 3D Web-клиент от орбиты до поверхности):** Логарифмический буфер глубины + камера-центрированная система координат для зума на 7 порядках масштаба ($10^7\text{ м} \to 1\text{ м}$), 3D-шейдер SPH-частиц (планковское/чернотельное излучение по температуре $T$, раскраска по давлению в ГПа, фазовым переходам, разрез/сечение внутренностей планеты), атмосфера (Rayleigh/Mie), океан с приливными волнами и **Cube-Sphere Quadtree LOD-поверхность** живой планеты, привязанная к лагранжевым трассерам SPH-коры и разрушающаяся в облако частиц при $D \to 1$.
- **R-6 (Процедурная флора, фауна и физическая связка с ударом):** Климатические биомы живой планеты (тропический лес, саванна, умеренный лес, тайга, альпийская тундра, коралловый риф/океан, степь), процедурная L-системная 3D-флора (многовидовые деревья, папоротники, кораллы/водоросли через `InstancedMesh`), процедурная артикулированная 3D-фауна (травоядные стада, хищники, птицы, морские виды с поведенческим ИИ). Физические воздействия рассчитываются от реального поля SPH с задержками распространения:
  - приливная деформация и мегацунами при сближении до предела Роша;
  - приход сейсмических P/S-волн ($t = d/v_P$, сотрясение и растрескивание коры);
  - радиационная тепловая вспышка ударного плюма ($\propto \sigma T^4$, самовоспламенение и лесные пожары);
  - баллистический дождь раскалённых тектитов/выбросов;
  - атмосферная ударная волна (избыточное давление $\Delta P$, повал деревьев, баротравма);
  - глобальная ударная зима / парниковый коллапс и количественный учёт выживаемости видов.
- **R-7 (Научная аналитика и валидация):** В реальном времени графики сохранения энергии ($E_{kin}, E_{pot}, E_{int}, E_{rad}, \Delta E/E_0$), углового момента $\mathbf{L}$, вириального отношения, пиковых $T$ и $P$, классификация исхода (слияние / hit-and-run / диск аккреции / разрушение $Q/Q^*_{RD}$), счётчик массового вымирания по биомам и гильдиям, экспорт телеметрии в CSV/JSON и набор научных пресетов (Земля–Тейя, удар по Меркурию, столкновение океанического мира, удар по газовому гиганту).

### Подтверждённые решения и допущения
- **A1 (Пользователь):** Старая игра переносится в `archive/factory-game/`, новая симуляция размещается в корне, создаётся Git-репозиторий.
- **A2 (Пользователь):** C++20 + CUDA (`nvcc`) вычислительный движок на RTX 4050 + локальный Web-клиент.
- **A3 (Архитектурный выбор под подтверждение):** Для фронтенда выбирается **Vite + TypeScript + Three.js + Vitest** (потребует разового `npm install` с выходом из песочницы для загрузки пакетов; альтернатива — полностью оффлайн Vanilla JS + чистый WebGL2). *Обоснование:* `Three.js` предоставляет `InstancedMesh`, `logarithmicDepthBuffer`, `EffectComposer`/Bloom, `ShaderMaterial` и матричную математику без написания тысяч строк шаблонного WebGL2-кода, а TypeScript + Vitest обеспечивают строгую проверку бинарного протокола и формул биосферы.
- **A4 (Пользователь):** Бесшовный орбитальный зум до уровня поверхности на одном процедурном планетоиде (Quadtree LOD-подмена сферы на участок коры с флорой/фауной, разрушающийся при ударе).
- **Проверенные факты окружения:** `nvcc` 13.4 (`V13.4.92`), `CUB=300500` (`-std=c++20 -arch=sm_89` скомпилирован и проверен на `RTX 4050 Laptop GPU` 6141 MiB), `g++ 16.2.1`, `cmake 4.4.5`, `gtest` + `zlib` (`pkg-config`), `Node v26.13.0`, `npm 12.2.2`, `Chromium 156`.
